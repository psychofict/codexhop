# Getting help

- **Something broke:** open a [bug report](https://github.com/psychofict/codexhop/issues/new?template=bug_report.yml).
  Run `codexhop doctor` first. It prints no tokens, so it is safe to paste; it can name an
  account's email, which you may want to edit out.
- **A question, or an idea to talk through:** open an
  [issue](https://github.com/psychofict/codexhop/issues/new?template=feature_request.yml).
- **A security problem:** report it privately through a
  [security advisory](https://github.com/psychofict/codexhop/security/advisories/new).
  Never paste a token, an `auth.json` or the contents of `~/.codex/codexhop/` anywhere public.
